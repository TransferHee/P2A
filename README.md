# P2A
This repository contains official PyTorch code for the Prioritized Patch Attack (P2A)

## Requirements
- Python == 3.10.8
- pytorch == 1.13.1
- torchvision == 0.14.1
- timm == 0.9.16
- captum == 0.7.0
- numpy == 1.26.4
- pandas == 2.2.1
- pillow == 9.3.0
- tqdm == 4.64.1
  
```bash
pip install -r requirements.txt
```
